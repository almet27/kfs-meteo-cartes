# KFS Météo Android — bêta
Widget natif Android 8+, utilisant les prévisions locales KFS /api/city-forecast. Choix manuel d'une commune partagée par tous les widgets, sans géolocalisation, sans compte, sans permission de localisation. Actualisation horaire au mieux selon Android. Les données ne sont pas des observations. La première bêta est compilée et signée en debug par GitHub Actions ; une clé de production privée et pérenne est indispensable pour les futures mises à jour. Ne jamais publier cette clé dans GitHub. Le workflow conserve la première bêta sans remplacer son APK par un autre signé différemment.
